### 3. Breast Cancer Prediction

**Description:**

Trained and compared multiple models—Logistic Regression, Decision Tree, Random Forest, SVM, and XGBoost—and evaluated performance with Accuracy, Precision, Recall, and F1 to support early detection and clinical decision-making.

**Skills Used:**
Python, Pandas, NumPy, scikit-learn, Data Cleaning, Exploratory Data Analysis (EDA), Feature Engineering, Classification (Logistic Regression, Decision Tree, Random Forest, SVM, XGBoost), Model Evaluation (Accuracy, Precision, Recall, F1), Visualization (Matplotlib/Seaborn)

### 4.Asthma Prevalence Prediction with Machine Learning

**Description:**
Predicted county-level current asthma prevalence (CASTHMA) across the U.S. using the CDC PLACES dataset. Combined behavioral, preventive, and spatial features (latitude/longitude with cyclical encodings); performed cleaning, feature selection, and scaling; trained and compared Linear/Ridge Regression, SVR, tuned Gradient Boosting, MLP, and Gaussian Process Regression (for spatial awareness and uncertainty). Evaluated models with R² and MSE, and summarized insights via feature importances and uncertainty intervals.

**Skills Used:**
Python, Pandas, NumPy, scikit-learn, SciPy, Data Cleaning, Feature Selection, Feature Engineering (cyclical spatial features), MinMax Scaling, Regression (Linear/Ridge/SVR/Gradient Boosting/MLP/GPR), Hyperparameter Tuning (RandomizedSearchCV), Model Evaluation (R², MSE), Visualization (Matplotlib/Seaborn) 

[🔗 View Project](https://github.com/HemaPriya-BA/Asthma-Prediction-ML-)
